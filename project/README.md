# Semester project: Team 12 LLaMA-style 500M workflow

The semester project is maintained separately from the audio laboratories:

- [Training, fine-tuning and evaluation workflow](https://github.com/ntua-el21026/ntua-llama-500m-nanotron).
- [Companion reports, configurations and selected checkpoints](https://github.com/ntua-el21026/ntua-llama-500m-artifacts).

These are two repositories for the same five-person Team 12 project. The report credits Evaggelos Asitzoglou, Panagiotis Avgerinos, Michail Athanasios Peppas, Andreas Saounatsos and Giannis Chatzigeorgiadis. Use their model card and provenance documents for experimental limitations and artifact access.

The selected 2025–2026 topic was **SPEC-1**, in Special Topics: *The Smol Training Playbook: The Secrets to Building World-Class LLMs*. Its [Hugging Face reference](https://huggingface.co/spaces/HuggingFaceTB/smol-training-playbook) discusses small-model training, curricula and datasets. It provides topic context; it is not evidence that every method or result from the playbook was implemented by the team.
